# VS-SDG: Visual Semantic-Guided Single Domain Generalization for 3D Object Detection

This repository contains the official implementation of:

**VS-SDG: Visual Semantic-Guided Single Domain Generalization for 3D Object Detection**

## Introduction

VS-SDG is a source-only single domain generalization framework for LiDAR-based 3D object detection. It uses visual semantic guidance from a frozen vision foundation model during training while preserving LiDAR-only inference.
